# FastAPI Book Management API

This project is a RESTful API built using FastAPI and SQLite for managing books. It demonstrates backend development concepts such as CRUD operations, modular architecture, database integration, search and filtering, statistical reporting, request validation with Pydantic, and API documentation through Swagger UI.

## Features

- Create, Read, Update, Delete (CRUD) operations
- Search books by title, author, price, and year
- Statistics endpoints using SQL aggregate functions
- SQLite database integration
- Modular project structure (Routers, Schemas, Database)
- FastAPI Swagger Documentation
- Pydantic data validation

## Tech Stack

- Python
- FastAPI
- SQLite
- Pydantic
- Uvicorn
- Git & GitHub
